## 🔧 Core Algorithm Files

### `gaOpt1.py` - Inner Genetic Algorithm
**Purpose**: Optimizes portfolio weights (8 ETFs)
**Input**: Return data, valid weight combinations
**Output**: Optimal portfolio weights
**Runtime**: 30-60 seconds per run

**Key Functions**:
- `generate_gene()` - Creates random valid portfolio
- `GA()` - Main GA loop for weight optimization
- `selection()`, `crossover()`, `mutation()` - GA operators

### `gaOpt2.py` - Outer Genetic Algorithm
**Purpose**: Optimizes walk-forward parameters
**Input**: Return data, valid weight combinations
**Output**: Optimal [train_period, test_period]
**Runtime**: Several hours

**Key Functions**:
- `generate_gene()` - Creates random [train, test] periods
- `GA2()` - Main GA loop for parameter optimization
- Calls walk-forward analysis for fitness evaluation

### `fitness_ga1.py` - Fitness Functions
**Purpose**: Portfolio evaluation metrics
**Functions**:
- `fitness_function()` - Scaled return-risk fitness
- `calc_riskAdjRet()` - Sharpe-like ratio
- `calc_returnOfPoints()` - Daily portfolio returns
- `findMinMax()` - Find extrema for normalization

### `walkforward.py` - Walk-Forward Analysis
**Purpose**: Out-of-sample validation framework
**Key Functions**:
- `walk_forward_split()` - Creates train/test windows
- `walkForwardOptimization3()` - Main walk-forward function
  - Runs GA1 on each train period
  - Evaluates on test period
  - Optionally saves daily returns to CSV

### `makeArrayOfWeights.py` - Weight Generation
**Purpose**: Pre-compute valid portfolio combinations
**Output**: ~165,000 valid weight arrays
**Functions**:
- `make_weights()` - Generates all valid combinations
- `is_valid()` - Checks portfolio constraints

## 🚀 Execution Scripts

### `main.py` - Main Optimization
**Purpose**: Find optimal walk-forward parameters
**Usage**: `python main.py`
**Runtime**: Several hours
**Output**: Best [train_period, test_period] and fitness value

**What it does**:
1. Loads return data
2. Generates valid weights
3. Runs GA2 optimization
4. Prints best parameters

### `make_csv_final_results.py` - Generate Portfolio Returns
**Purpose**: Create daily returns for three risk profiles
**Usage**: `python make_csv_final_results.py`
**Runtime**: 3-6 hours total
**Output**: 
- `dailyReturn_highRisk.csv`
- `dailyReturn_lowRisk.csv`
- `dailyReturn_normalRisk.csv`

**Parameters Used**:
- High Risk: train=50, test=5
- Low Risk: train=250, test=10
- Normal Risk: train=245, test=35

### `checkOutlier.py` - Outlier Visualization
**Purpose**: Visualize outliers in return data
**Usage**: `python checkOutlier.py`
**Output**: Box plot display

## 📓 Jupyter Notebooks

### `data/prepare_data.ipynb`
**Purpose**: Data preprocessing
**Input**: `data/data.csv`
**Output**: `logRetData.csv`, `simpleRetData.csv`
**Steps**:
1. Load raw price data
2. Convert to datetime
3. Calculate log returns
4. Calculate simple returns
5. Rename columns (close_* → ret_*)
6. Save to CSV

**Purpose**: Results analysis and visualization
**Input**: 
- `dailyReturn_highRisk.csv`
- `dailyReturn_lowRisk.csv`
- `dailyReturn_normalRisk.csv`
- `logRetBenchETF.csv`
**Output**:
- Performance metrics CSV
- Cumulative return charts
- Drawdown charts
- Statistical test results
**Steps**:
1. Load portfolio returns
2. Calculate metrics (Sharpe, drawdown, etc.)
3. Statistical tests (normality, variance, means)
4. Generate visualizations
5. Save charts and tables

## 🔄 Data Flow

```
1. DATA PREPARATION
   data.csv 
      → prepare_data.ipynb 
      → logRetData.csv

2. OPTIMIZATION
   logRetData.csv 
      → main.py (GA2 + GA1 + Walk-Forward)
      → Optimal parameters printed

3. RESULTS GENERATION
   logRetData.csv + Optimal parameters
      → make_csv_final_results.py
      → dailyReturn_*.csv files

4. VISUALIZATION
   dailyReturn_*.csv + logRetBenchETF.csv
      → evaluationOfResults.ipynb
      → Charts (PNG) + Metrics (CSV)
```
